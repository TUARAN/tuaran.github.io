# 掘金安东尼 - 个人主页

> 全栈开发者 / 技术博主，我相信，能穿越时间的一定不是一时的热闹，而是深度价值带来的长期回响

一个现代化的个人主页，展示技术能力、项目作品和个人信息。基于 ZYYO 主页模板定制开发。

## 🌟 特色功能

- **响应式设计** - 完美适配桌面端和移动端
- **白天/黑夜模式** - 一键切换主题模式
- **现代化UI** - 简洁美观的界面设计
- **项目展示** - 展示个人作品和技术项目
- **技能展示** - 可视化技能树
- **时间轴** - 个人成长历程
- **社交链接** - 快速访问各种社交平台
- **贪吃蛇游戏** - 内置小游戏彩蛋

## 🚀 快速开始

### Docker 部署（推荐）

1. 克隆项目
```bash
git clone https://github.com/TUARAN/tuaran-github-io.git
cd tuaran-github-io
```

2. 修改 Caddyfile 中的域名
```bash
# 编辑 Caddyfile，将 example.com 替换为你的域名
vim Caddyfile
```

3. 一键部署
```bash
docker compose up -d
```

### 传统部署

1. 下载项目文件
2. 将文件上传到 Web 服务器
3. 配置 Web 服务器（Nginx/Apache）
4. 访问你的域名即可

## 💻 使用说明

### 文件说明
- `/index.html` - 主页面文件
- `/static/css/root.css` - 主题样式文件
- `/static/css/style.css` - 样式文件，可修改字体
- `/static/img/favicon.ico` - 网页图标和头像
- `/static/js/script.js` - JavaScript 功能文件

### 自定义配置
1. **个人信息** - 编辑 `index.html` 中的个人信息
2. **项目展示** - 修改项目列表和链接
3. **技能图标** - 替换 `/static/svg/` 中的技能图标
4. **主题样式** - 修改 `/static/css/root.css` 中的 CSS 变量
5. **域名配置** - 修改 `Caddyfile` 中的域名设置
